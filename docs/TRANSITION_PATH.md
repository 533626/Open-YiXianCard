# 境界过渡路径与互换性聚类（符咒姜袭明）

> 方法：`analysis/campaign/transition.py`。**过渡路径**：对每份随机获取供给（逐轮累计、名字按境界解锁时点抽牌，14 份），R2–R20 逐轮搜候选阵
> （受该轮累计供给约束；元婴起留空 / 8 张两种；一半候选用上一轮候选作种子），对**当轮真实对手**独立评估胜率，再用动态规划每轮选一副阵，最小化
> `Σ (1 − 胜率) × 输一场掉的命元 + μ × 相邻两轮换牌数`。**互换性聚类**：对各阶段高胜率阵的每个位置，把牌换成每张候选牌得到替代损失矩阵，对称化后平均连接聚类（阈值 0.04）。

## 过渡路径结果（三个版本；μ = 每换 1 张牌折合的命元）

| 版本 | 期望总命元损失（R2–R20） | 相邻换牌总数（μ = 0 → 0.25） | 备注 |
| --- | --- | --- | --- |
| A 基础（每轮 2–4 个候选，与上一轮无关） | 95.5 ± 6.2 | 61.7 → 53.8 | 候选少且彼此差异大，μ 几乎无效 |
| B 带换牌惩罚的候选（再加「从上一轮最好阵出发、惩罚换牌」的局部搜索） | **72.8 ± 5.1** | 50.7 → 38.9 | 候选质量和贴近程度都提高；μ 从 0 到 0.25 命元只涨 0.6，换牌少 23% |
| C = B + 修为约束（按时突破需炼掉的牌从供给里扣除） | 190.7 ± 9.6 | 29.9 → 24.1 | **12 / 14 份供给下按时突破不可行**，见下 |

- **B 是当前最可信的估计**：平滑几乎不花命元（每少换 1 张牌 ≈ 几乎 0 命元）。分阶段损失（B）：筑基 1、金丹 7、元婴 2、化神 62；化神各轮胜率 R12 0.82 → R13 0.66 → R14 0.61 → R16 0.55 → R18 0.52 → R20 0.93；金丹入口 R5 / R6 / R7 为 0.78 / 0.49 / 0.99。
- **C 说明炼化燃料是绑定约束**：固定钟（R3 / 5 / 8 / 12）要求到 R12 累计修为 55，扣掉自然 +1 / 轮，要炼约 44 张牌，而到 R12 累计获得约 80 张，其中 8 张在阵上。我的扣除模型偏保守（保护当轮前 3 副候选阵的全部名字、不计合成送的修为、先炼单张），所以 190.7 与「按时突破不可行」的份数 12 / 14 只能当悲观上界；真实在 72.8 与 190.7 之间，live 真人能按 R11 突破说明实际比这里宽松。
- **结论**：升阶投入（重复牌）与突破燃料在抢同一份供给——哪些牌当燃料很关键，应该优先炼**可互换角色位里的富余牌**（见下节聚类），保住不可互换的关键牌。
- 第一版（A）的「平滑几乎不影响命元」在 B 里依旧成立，并且换牌总数可以压到 39–44。

## 接入仿真（姜袭明，种子 80000，n=300，同种子配对；`--fixed-plan auto` = 固定钟 + 专属仙命 + R4 自在随心）

| 臂 | 名次 | 对同条件基线 |
| --- | --- | --- |
| v2 默认（未固定任何部分） | 3.38 | — |
| 基线：固定部分（专属仙命） | **3.66** | — |
| T1 + 每轮目标牌表（plans/jxm-targets.json，非目标牌先炼先换） | 3.70 | +0.04 ± 0.08（无效） |
| T2 = T1 + 布阵器最多留 3 个空格 | 3.65 | −0.01 ± 0.08（无效） |
| T3 仅最多留 3 个空格 | 3.69 | +0.03 ± 0.04（无效） |

- **三个臂都没有可测的效果。** 目标表在阵上的命中率只有 0.14–0.20（R5–R14；R18 0.48），升阶预算 U 只有 1.9–2.6（live 11–12）：只在炼化 / 置换排序里保护目标牌，布阵器照样按「当前胜率」摆阵，**不会围绕目标牌去收、去升阶**。
- **固定部分本身比 v2 默认差 0.28 名**（3.66 对 3.38；早期用自编仙命优先级是 3.50）。固定钟、选专属仙命、R4 自在随心三者的各自贡献没有拆开；按本角色专属选仙命比布阵器逐候选评估差。
- 教训：对比基线必须用与被测臂**同一版固定部分**重跑；我先用了早期基线（3.50），得到过「+0.16–0.21 更差」的假象（R3 −11pp 是仙命选择不同，不是被测改动）。

### 目标牌为什么没被收上来（诊断 + 四个后续臂）

- **诊断（T1，100 局）**：目标牌名「拥有（手 + 阵）/ 其中在阵上」：R5 1.35 / 1.29（目标 6 张）、R8 1.24 / 1.24（6）、R10 1.49 / 0.98（4）、R14 1.87 / 1.31（5）、R18 4.50 / 3.21（8）。
  **拥有的几乎都已经上阵，问题在「没拿到」而不在「没摆上」**，所以给布阵器加目标牌偏好帮不上忙。
- 又试了三个可能的瓶颈（同条件基线 3.66，对基线）：**保护窗口**（当轮起向后几轮的目标牌都不先炼先换）窗口 4：3.78（+0.12 ± 0.07）、窗口 8：3.67（+0.01 ± 0.07）；
  **放宽手牌上限**（v2 默认 4，每轮把手牌炼到 ≤ 4 张）窗口 4 + 上限 8：3.77（+0.11 ± 0.08）、窗口 4 + 上限 12：3.78（+0.12 ± 0.07）。**全部无效**。
- 结论：**只改炼化 / 置换的排序不能把目标牌收上来**。离线路径里每轮的最优阵假设「累计拿到的牌全在手里、不为修为炼牌」，而仿真里为修为要炼约 44 张、每轮花几次置换抽牌都是随机的——
  目标牌拿到的数量被抽牌概率和燃料需求共同限制，不是排序问题。下一步应该是**把置换改成定向的**（抽到目标牌就留、在新牌池里集中换）并**让炼化燃料取自可互换角色位的富余牌**，而不是继续加保护规则。
- 早期基线 3.50（自编仙命优先级）与正确基线 3.66（专属仙命）不同，比较必须用同版固定部分重跑基线。

## 收工结论（2026-09-30）

- **离线能算出来的**：各境界的核心牌合集（按不可替代性筛掉搭车牌，含七星定魂留空末格）、按境界解锁时点累计的获取模型（与 live 对上：R14 化神牌期望 5.0 张 = live 0.62 × 8）、
  互换性聚类、每轮最优阵的过渡路径（期望命元损失 ≈ 72.8，其中 81% 在化神；平滑几乎不花命元；炼化燃料是绑定约束）。
- **接进仿真后无效的**：目标牌表保护（窗口 1 / 4 / 8）、放宽手牌上限、布阵器多留空格、定向置换、互换角色位燃料、机制组攒机会；对同条件基线 3.66 均在 ±0.15 内，其中多数略差。
  仿真里目标牌的拥有数本身就低（R5 1.35 / 6），主要受抽牌概率与炼化燃料需求限制。
- **固定部分（固定钟 + 专属仙命 + R4 自在随心）本身比 v2 默认差 0.28 名**（3.66 对 3.38），这是比任何上层策略都大的差距；三者的各自贡献尚未拆开。
- 所有新开关（`--targets` / `--target-window` / `--max-empty` / `--directed` / `--roles` / `--gplan` / `--fixed-plan`）默认关闭，不影响默认路径。
- 若重启这条线，建议先拆开固定部分三项的贡献，再谈上层策略；离线路径里的 72.8 假设累计牌全留手且不为修为炼牌，仿真里要炼约 44 张燃料，两者之间的差距才是要解释的。

## 互换性聚类（可互换 = a 换成 b 后独立胜率平均掉 ≤ 0.04 且双向成立）

- 筑基：{揽雀尾、金鸡独立、落雷术}（普通输出）、{震卦、艮卦}（卦象供给）。
- 金丹：{星弈•夹、星弈•打}、{野马分鬃、金鸡独立、斩草除根}、{落雷术、火云符}、{奔雷符、白蛇吐信}、{藕断丝连、星弈•点、掌心雷、螳螂捕蝉、斗转星移、飞星刺、寒冰咒}（一大组低影响牌）、{众星拱月、落花有意}（存疑，见局限）。
- 元婴：{星弈•打、星弈•夹}、{落雷术、金鸡独立、揽雀尾}、{反震心法、瘴气符}、{蜻蜓点水、白蛇吐信}、{气疗术、斩草除根}、{斗转星移、水气符}。
- 化神：16 张参与聚类的牌只有 1 组可互换（扰心符、镇魂封元符），其余 14 张各自独立——**化神的关键牌几乎不可互换，低阶段的普通输出牌大量可互换**。

## 局限

- A / B 的供给假设累计获得的牌全部留手、不为修为炼牌，所以是乐观的；B 的 72.8 是乐观下界，C 的 190.7 是悲观上界。
- C 的修为扣除模型偏保守（见上），没有考虑合成送的修为、手牌超 12 张不抽改加修为、以及炼化时保留哪些牌的更优选择。
- 聚类阈值 0.04 与测量噪声（约 0.03）同量级，个别组（如 众星拱月 + 落花有意）可能是噪声。
- 只做了姜袭明 × 符咒；对手用当轮真实人机。
